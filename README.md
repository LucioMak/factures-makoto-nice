# Factures Makoto Nice

Appli de facturation de Karaté Makoto Nice Saint-Roch, à installer sur le téléphone.

## Mise en ligne sur GitHub Pages
1. Créer un dépôt (par exemple `factures-makoto-nice`) et y déposer tout le contenu de ce dossier, `index.html` à la racine.
2. Dans le dépôt : Settings > Pages > Source « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. L'adresse sera du type `https://<ton-compte>.github.io/factures-makoto-nice/`.

## Installation sur Android (Pixel)
Ouvrir l'adresse dans Chrome, puis appuyer sur « Installer l'appli » en haut de la page (ou ⋮ > « Installer l'application »).

## Sur iPhone
Safari > Partager > « Sur l'écran d'accueil ».

## Données
Les factures et réglages restent sur le téléphone (rien n'est envoyé sur GitHub).
Réglages > « Exporter une sauvegarde » de temps en temps ; « Importer une sauvegarde » pour tout retrouver sur un autre téléphone.

## Mise à jour de l'appli
Remplacer les fichiers dans le dépôt et changer `VERSION` dans `sw.js` (ex. `factures-mkn-v2`).
